# Moved: Deterministic Encodings for COSE

The COSE draft that used to live here is now maintained in its own repository:

**<https://github.com/action-state-group/cose-deterministic-encodings>**

It is `draft-mih-sokolov-cose-deterministic-encodings` (*Deterministic Encodings
for COSE*), the successor to the `draft-mih-sokolov-cose-det-encodings` working
copy that was here. The header parameter it defines is `deterministic-encodings`,
which replaces the earlier name `payload-preimage-encoding`. That repository also
holds the reference emitter and verifier and the test vectors.

The copy here was removed so the two cannot diverge. Its history is still in
this repository's git log, and the review threads from its development stay on
this repository's pull requests. Please open issues and pull requests for the
COSE draft on the standalone repository.
